A one-line comedy patch note for a bug in human biology: as of v4.2.0, the brain no longer queues every embarrassing moment since 2009 for 2 a.m. playback at unmutable volume. The program writes the entry line to entry.txt in the output directory.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
